# Task: Website Theme Redesign & Exploration (3 Variations)

## Goal
Implement and test 3 distinct modern design themes for the RemLays landing pages to replace the Claude/Anthropic-inspired aesthetic (warm terracotta, Fraunces serif, mocha dark mode).

## 3 Theme Variations
1. **Theme 1: Linear / Dev-First Dark**
   - Slate & Deep Zinc palette (#08090d, #11141c)
   - Electric Indigo (#6366f1) & Cyan accents (#06b6d4)
   - Sans-serif typography (Inter / Geist + JetBrains Mono)
   - Technical grid lines and command-palette style cards

2. **Theme 2: Obsidian Luxury / Glassmorphism**
   - OLED True Black (#030305)
   - Ice Silver/White (#ffffff) & subtle metallic glow
   - Modern geometric sans (Plus Jakarta Sans)
   - Frosted glass cards with luminous borders

3. **Theme 3: Vibrant Neo-Digital**
   - Deep Graphite background (#0b0c10)
   - Dual-tone electric aurora mesh gradients (Electric Amber #f59e0b + Hyper Violet #8b5cf6 + Neon Blue)
   - Dynamic fluid cards and glowing hover animations

## Implementation Steps
- [ ] Create website/themes.css with CSS variables, typography imports, and styling overrides for each theme.
- [ ] Create website/theme-switcher.js floating toolbar so themes can be switched with 1 click in real time.
- [ ] Integrate into website/rem-lays-hero.html and website/rem-lays-download.html.
- [ ] Test all 3 themes visually and capture previews for final user selection.
