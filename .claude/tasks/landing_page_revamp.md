# Landing Page Revamp

## Goal
Revamp the Rem-Lays landing page to make it highly premium, dynamic, and visually stunning ("tagda"). Stop using basic CSS blobs and move to a modern, glowing aurora/mesh background, premium typography, and advanced glassmorphism.

## Reasoning
The current design is perceived as "farzi" (boring/fake). A more engaging, aesthetic design builds trust, excites users, and represents the brand better. It needs micro-interactions and smooth animations to feel alive.

## Tasks
- [x] 1. Update `index.html` structure to add GSAP (via CDN) and adjust markup for advanced background effects.
- [x] 2. Update `style.css` to implement the new design system (tokens, aurora effect, noise texture, premium glassmorphism).
- [x] 3. Update `main.js` to add advanced GSAP animations, a 3D tilt parallax on the hero image, and spotlight hover effects on the feature cards.
- [x] 4. Verify functionality and responsive design.

## Implementation Details
We will be injecting GSAP from CDN into `index.html` since it was approved. We will use `style.css` for structural layout and base styles, and `main.js` to animate the hero section, the aurora blobs, and the glass cards.
